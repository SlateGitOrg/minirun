# Example bundles

- `minimal/config.json` - generated by
  `minirun spec -o examples/minimal/config.json --hostname minimal --memory 64M --pids 64 -- /bin/sh`.
  Put a root filesystem in `examples/minimal/rootfs` (for example the Alpine
  minirootfs, see the README quickstart) and run
  `sudo minirun run --bundle examples/minimal --rm demo`.
- `runc-style/config.json` - a config in the shape `runc spec` writes, with
  keys minirun does not implement. `minirun validate --bundle examples/runc-style`
  rejects its ambient capabilities (they are not inheritable); `make demo`
  validates a copy with the ambient list emptied to show the
  unsupported-key warnings.
